## 4. AI 能力与「AI 通道」

### 默认（离线，零配置）

- 一句话解析、分类、分摊、多币种折算、审计、预算、统计、洞察、小作文：**全部由本地规则引擎完成**，毫秒级、不联网、不需要 Key。
- 票据/订单截图：内置样例演示同一条识别流水线，结果**明确标注为「内置样例」**。

### 可选增强（自备 Key，与前任无关）

在 `server/.env` 里配置（参考 `server/.env.example`），启动后端后 Demo 右上角徽标会变成 `☁️ AI 已连接`：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1   # 任何 OpenAI 兼容接口均可
LLM_MODEL=deepseek-flash
VISION_MODEL=deepseek-flash
DEEPSEEK_API_KEY=你的Key                    # 也可用环境变量注入，勿写入仓库
NPU_FALLBACK=0                              # 本机端侧模型回退开关（可选）
```

**行为约定**：Demo 通过 `GET /api/ai/engine` 探测通道；探测失败/超时（1.5s）→ 显示「🔌 离线模式」，
所有功能照常可用（`fetch` 在 `file://` 下受限属正常现象，不代表故障）。

## 5. 已知限制与坑（请务必先读）

| # | 坑 / 限制 | 说明与建议 |
|---|---|---|
| 1 | **同步只覆盖同一浏览器** | Demo 已接 `utils/sync.js`：同浏览器多窗口是**真实同步**、刷新不丢；但**跨设备/跨浏览器**仍需要后端通道。徽标**只在真的探测到第二个窗口后**才显示"多窗口已同步"，探测不到就显示"已开启本地留存"（实测 `file://` 下 localStorage 可用，刷新不丢）。要做跨设备多人，接 server 的房间接口 + WebSocket/轮询 |
| 2 | **小程序端 UI 未与新 Demo 统一** | `apps/miniprogram` 是小程序原生页面，视觉仍是旧版；如需统一，按 `demo/index.html` 的设计语言重写 wxss |
| 3 | 无鉴权 | server 与云函数均为 Demo 级，没有登录态校验/权限体系，**不要直接暴露到公网** |
| 4 | `file://` 下 fetch 受限 | 所以 AI 通道探测基本会失败 → 走离线模式，这是预期行为。要联网能力就把 Demo 放到 http 服务下 |
| 5 | 浏览器缓存 | 改完 `demo/index.html` 后如看到旧界面，用 **Ctrl + F5** 强刷 |
| 6 | 语音输入依赖浏览器 | Web Speech API 在部分浏览器/内核不可用；代码里已有降级提示（不会报错） |
| 7 | 账单时间与统计 | 统计按 `bill.createdAt` 聚合，历史数据若无该字段会被跳过；新增账单统一走 `makeBill()` 生成 |
| 8 | 不要提交 `server/.env` 与数据库 | `.gitignore` 已忽略 `.env`、`server/data/`、`*.db*`、`tests/.output/`；`server/data/` 由程序自动创建 |
| 9 | 微信云函数 `ocr` | 需要自己申请腾讯云 OCR 的 SecretId/Key 才能真跑（见 `docs/部署与配置.md`） |
| 10 | **改对比度/颜色要动令牌** | 文字颜色一律用 `:root` 里的令牌（`--pri-ink` 白底橙字 / `--on-pri` 橙底字 / `--g400`…）。写死 hex 会让 `#uitest` 的对比度体检失败。品牌橙 `--pri` **只当填充用**，当文字用只有 2.84:1 |
| 11 | **改同步层要先看 `架构与实现.md` 第五-②节** | `rev` 必须全局单调、发布前要按内容 diff 盖 `updatedAt`、删除必须留墓碑、合并后要 `reseedCounters()` —— 每一条都是实测踩过的坑，删掉任何一条都会静默丢数据 |
