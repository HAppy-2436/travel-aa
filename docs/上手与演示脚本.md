# 🚀 上手与演示脚本

> 两部分：**怎么跑起来**（10 分钟）+ **怎么讲**（3 分钟 / 8 分钟两套动线）。

---

## 一、跑起来

### 1. 网页 Demo（主交付物，零配置）

1. 双击 `demo/index.html`（Chrome / Edge 打开）
2. 右上角点 `🩺 自检` → 出现 **13 / 13 PASS** 即表示环境就绪
3. 右上角点 `＋` 把手机加到 **3~4 台**（每台 = 一个真实用户）
4. 点 `▶ 自动演示` 看完整流程（**会自动切页面，顶部字幕同步解说**，约 20 秒）：
   ① 开场 → ② u1 创建房间（切到房间详情）→ ③ 其他人输房间号加入（各自切到房间页）→
   ④ u1 一句话 AI 记账（展示解析结果后提交）→ ⑤ u1 粘贴携程订单入账 → ⑥ 小红票据识别（含扫描动画）
   → ⑦ 小李记日元（多币种折算）→ ⑧ u1 一键结算 → ⑨ AI 生成旅行小作文 → ⑩ 消费复盘（收尾三台手机停在结算/统计/房间）
5. 点 `🎬 导览` 进入 15 步讲解模式（同类功能已合并）：`← 上一步 / ▶ 自动 / 下一步 →`（每一步都会高亮对应功能块，4 台手机各有 ≥3 个环节）

> 也可以用键盘/鼠标直接操作任意一台手机：记一笔、拍照识别、携程订单、结算、统计，**所有手机实时同步**。

### 2. 关键交互都在哪

| 想演示什么 | 点哪里 |
|---|---|
| AI 一句话记账 | 任一手机 → 房间 → `＋ 记一笔` → 顶部输入框（或点「💡 换个例子」）→ `🤖 AI 识别` |
| 语音记账 | 记一笔页 → `🎙️ 语音`（需要浏览器支持麦克风与 Web Speech API） |
| 多币种 | 记一笔页 → 金额下方选 `¥ 日元` 等 → 金额下方实时显示折算 |
| 票据识别 | 房间 → `📷 拍照` → 选类型（微信/支付宝/小票/发票）→ 点拍照 → 勾选 → 导入 |
| 携程订单入账 | 房间 → `📷 拍照` → 切到 `🧳 携程订单` → 选内置样例 → `🔍 解析订单` → 导入 |
| 订单截图识别 | 同上页面向下 → 「订单截图识别」→ `🔍 识别这张截图` → `入账这笔订单` |
| AI 审计 / 预算预警 | 房间详情页（记几笔账后自动出现） |
| 一键结算 + 小作文 | 房间 → `结算` → 底部可 `📋 复制方案` / `📄 旅行报告` / `✍️ 生成小作文` |
| 消费统计 | 任意页面右上角 `STATS` |

### 3. 跑测试（可选，Node ≥ 18）

```bash
node tests/ai.test.js        # 62 项
node tests/v2.test.js        # 133 项
node tests/demo.check.js     # Demo 完整性检查
```

### 4. 小程序端（可选）

1. 微信开发者工具 → 导入项目 → 选择 `travel-aa` 根目录（`project.config.json` 已指向 `apps/`）
2. 不配置云开发也能跑：`apps/miniprogram/utils/db.js` 内置**演示模式**，本地造数据
3. 要接真实云开发：按 `docs/部署与配置.md` 第三节操作

### 5. 自建后端 + AI 增强（可选）

```bash
cd server
npm install
npm start          # http://localhost:3000/api/health
```

配置 Key（**自备**，勿用他人）：复制 `.env.example` 为 `.env`，填 `DEEPSEEK_API_KEY` 等。
不配 Key 也能启动，AI 相关接口自动降级为规则引擎；Demo 右上角会显示 `🔌 离线模式`。

## 二、演示脚本

### A. 3 分钟极简版（评委走过场 / 时间紧）

| 时间 | 动作 | 要讲的一句话 |
|---|---|---|
| 0:00 | 加手机到 3 台，指屏幕 | 「每台手机就是一个真实用户，操作实时同步——这就是多人 AA 的真实场景。」 |
| 0:30 | 记一笔页 → 点「换个例子」→ AI 识别 | 「说一句话就能记账：口语数字自动归一化，金额、分类、付款人、分摊一次填好。」 |
| 1:00 | 切到「携程订单」→ 选样例 → 解析 → 入账 | 「携程订单直接变账单——机票酒店门票不用手工补录，行程即账本。」 |
| 1:45 | 房间页下滑 → AI 审计 | 「AI 会审计账单：重复记账、账不平、异常大额都能查出来。」 |
| 2:10 | 结算页 | 「一键清账：贪心算法给出最少转账笔数；外币按记账时汇率快照折算，账恒平。」 |
| 2:40 | 点右上 `STATS` → 再点 `🩺 自检` | 「消费复盘 + 20 项自检全过，现场不会翻车。」 |

### B. 8 分钟完整版（正式路演）

按 `🎬 导览` 的 15 步走，每步讲解词就是导览卡片里的文案（下表是功能分组；导览把同类功能并成一步讲）：

1. **多机联动演示台**——加手机、实时同步
2. **每台手机 = 一个用户**——垫付分散的真实痛点
3. **创建/加入房间**——6 位房间号，共享一本账
4. **会听：一句话/语音记账**
5. **会看：票据识别**
6. **会读单：携程订单入账**
7. **会算账：多币种 + 最简转账**
8. **会复盘：统计 + AI 审计 + 小作文**

收尾建议加一句：`🩺 自检 22/22` 与 `npm test`（9 套 / 823 项断言全绿），说明工程可复现。

      探测到对端后工具条徽标会变成 `🔗 多窗口已同步`（探测不到就显示 `💾 已开启本地留存`，不会虚报）

## 四、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 改了页面没变化 | 浏览器缓存，按 **Ctrl + F5** 强刷 |
| 工具条显示「🔌 离线模式」 | 正常：没启动 server 或 `file://` 下禁止跨源请求。所有功能仍可用 |
| 工具条显示「📴 单页联动」 | `localStorage` 探测失败时才会出现（少见）→ 自动降级。想演示多窗口同步就用本地服务器打开 |
| 工具条显示「💾 已开启本地留存」 | 正常：已能刷新不丢，但**还没探测到第二个窗口**。再开一个标签页打开同一路径即会变成「🔗 多窗口已同步」 |
| 语音按钮提示不支持 | 浏览器不支持 Web Speech API，改用文字输入即可 |
| 点「AI 识别」说没识别出金额 | 换内置示例；解析需要句子里有金额（阿拉伯数字或中文数字都行） |
| 统计页空白 | 房间还没有账单，先记几笔（自动演示会一次性补齐） |
| 页面打开是空白 | 打开控制台看报错；确认 `demo/assets/vision-samples.js` 与 `apps/miniprogram/utils/{ai,ctrip,sync}.js` 未被移动 |
| 演示时想快速退出弹窗/导览 | 按 `Esc` 逐层退出（弹窗 → 导览 → 演示模式） |
