# 🔍 产品效果怎么验（5 分钟版）

> 面向**要看效果的人**（评委 / 队友 / 自己）。全部离线可跑，不需要服务器、不需要 API Key。

## 第 0 步：打开

双击 **`demo/index.html`**（Chrome / Edge 均可）。桌面已放好快捷方式 **`TravelAA 演示`**。

> ⚠️ 必须保持目录结构：`demo/index.html` 会引用 `../apps/miniprogram/utils/ai.js`、
> `ctrip.js`、`assets/vision-samples.js`。**不能只拷 index.html 一个文件**。
> 整个 `travel-aa/` 目录一起拷即可。

打开后右上角会显示 `🔌 离线模式 · 本地规则引擎`（正常！没启后端就是离线规则引擎，功能不受影响）。

### 想让多人视角一开场就出现？

默认是 **1 台手机**（工具栏显示 `📱 1人`），需要点 `＋` 加到 3~4 台。
如果不想点，可以直接在地址后面加参数：

| 打开方式 | 效果 |
|---|---|
| `demo/index.html` | 1 台手机（默认，`＋` 会呼吸高亮提示你加人） |
| `demo/index.html?n=3` | **3 台手机开场**（推荐演示用） |
| `demo/index.html?n=4` | 4 台手机开场 |
| `demo/index.html?n=4#uitest` | 4 台开场并自动跑交互验收 |

> `＋ / −` 也可以随时调整，范围 1~4 台。**每台手机 = 一个真实用户**，操作在所有手机上实时同步。

## 路线 B：自己点一遍（3 分钟，推荐，能真正感受产品）

### ① 先把人凑齐
工具栏点 **`＋`** 两次 → 变成 **`3 人`**（3 台手机 = 3 个真实用户视角）。

### ② 建房间（第 1 台手机）
点 `＋ 创建房间` → 填「国庆东京行 / 东京」→ 点「创建房间」。
**注意看**：3 台手机同时跳到房间页（这就是"实时同步"）。

### ③ 其他手机加入
第 2 台手机点 `加入房间` → 输入房间号（第 1 台手机房间卡片上显示的那 6 位）→ 加入。

### ④ 试 AI 一句话记账（核心卖点）
第 1 台手机点底部 `＋ 记一笔` → 在 AI 输入框里输入：

```
打车去机场86块，我垫的，和小红小李平分
```

点 **`AI 识别`** → 金额、分类、付款人、分摊对象**自动填好** → 点 `确认记账`。

> 也支持语音：点 🎙️ 直接说话（需浏览器支持 Web Speech API）。
> 中文数字也能懂：「昨天晚上吃火锅三百二十八」→ 328。

### ⑤ 试携程订单入账（赛道契合点）
底部点 `📷 拍照` → 切到 **`🧳 携程订单`** 页签 → 选一个内置样例（机票/酒店/门票）
→ 点 `解析订单` → 点 `导入`。订单文本会自动变成 AA 账单。

### ⑥ 试多币种（真实出境场景）
再记一笔时把币种切成 **`¥ 日元`**，金额填 `12000`。
它会计下**记账时的汇率快照**，结算时按快照折算人民币 —— 账恒平，不会因为汇率波动对不上。

### ⑦ 试一键结算（算法亮点）
点底部 `结算` → 看到：
- 每人应收 / 应付
- **最简转账方案**（贪心算法：4 人 8 笔账压缩到 3 笔转账，转账次数最少 = 社交尴尬最少）
- 点 `复制方案` 可粘贴到微信

### ⑧ 试消费统计与 AI 复盘
房间页右上角 `STATS` → 分类占比、每日趋势、**AI 消费洞察**、入账方式统计。

## 已知效果边界（对外表述请诚实，别说过头）

| 说法 | 是否可以说 | 依据 |
|---|---|---|
| 「订单文本 / 截图 → 账单」的识别入账管线已打通 | ✅ | 逻辑已实现且可现场演示 |
| 多币种折算、账恒平、贪心最简转账 | ✅ | 有单测 + 浏览器内自检 |
| AI 审计与消费洞察、旅行小作文 | ✅ | 离线规则引擎实现 |
| 「4 台手机实时同步」 | ✅ 可以说（但要说清范围） | Demo 已接上 `utils/sync.js`：**同一浏览器多开窗口**是真实同步（BroadcastChannel + localStorage，刷新不丢）。跨设备/跨浏览器仍需要后端通道（`server/` 已有 REST 接口）。同步能力是运行时探测的，工具条徽标会如实显示当前是 `🔗 多窗口已同步` / `💾 已开启本地留存` / `📴 单页联动` 哪一档；徽标只在**真的探测到另一个窗口**后才显示"已同步" |
| 「已接入携程系统」 | ❌ 不能说 | 当前是**订单文本解析**；自动拉单需携程开放平台授权（对接点已预留） |
| 「截图识别 = 模型实时输出」 | ❌ 不能说 | 未连 AI 通道时展示的是**内置样例结果**，页面已明确标注「内置样例识别结果」 |
| 「单文件、双击即开」 | ❌ 不能说 | 实际还依赖 3 个 UMD 内核脚本 + 1 个样例素材，**整个目录一起拷**才能双击打开。正确说法：「拷整个目录，双击 `demo/index.html` 即可离线运行」 |
| 「无障碍达标」 | ✅ 可以说，有代码依据 | `#uitest` 逐个文本节点算对比度（WCAG 2.1 AA）、校验弹层 `role`/`aria`、真实派发 `Esc`/`Tab`/`Enter` 验证键盘闭环 |
| 「离线可用」 | ⚠️ 有小保留 | 功能全离线可用；但字体来自 Google Fonts，断网时静默降级为系统字体，观感略有差异 |
