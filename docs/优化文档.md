## 一、参赛目标解读

### 1.1 赛事性质

携程高校 AI HACKATHON 是面向高校团队的 **AI 主题黑客松**，赛题集中在"AI + 旅行"场景
（参考同届获奖作品方向：多模型协同的智能随行导游、智能行程规划等）。
区别于普通软件设计大赛，评委的核心关注点是：

| 维度 | 评委真正想看到的 | 权重（估） |
|---|---|---|
| **AI 技术深度** | 是否真的用了 AI（大模型/多模态/智能算法），而不是"带个 OCR 的 CRUD" | ★★★★★ |
| **创新性** | 场景切入点是否新颖，AI 用法是否让人眼前一亮 | ★★★★ |
| **产品完成度** | 主流程闭环、可演示、可体验，不是 PPT 作品 | ★★★★ |
| **商业价值 / 赛道契合** | 是否契合携程的旅行生态，能否落地产生价值 | ★★★ |
| **演示表现** | 现场 3-5 分钟能否讲清楚、演示顺滑不翻车 | ★★★ |

### 1.2 我们的参赛叙事（优化后应达到的定位）

> **TravelAA —— 懂旅行、会读票据、能聊天的 AI 结伴记账官**
>
> 旅行 AA 的痛点不是"算不平"，而是"记账烦"：垫付分散、票据散落聊天记录、事后对账尴尬。
> TravelAA 用 **三层 AI 能力** 把记账成本压到"说一句话 / 拍一张图"：
> 1. **AI 一句话记账**：自然语言 → 结构化账单（金额、分类、付款人、分摊对象一次解析）
> 2. **AI 票据识别**：微信/支付宝截图、小票 → 自动提取金额、商户、时间、分类
> 3. **AI 消费洞察**：自动产出旅行消费报告、结算摘要、省钱建议，一键分享
>
> 结算端用贪心最简转账算法收尾，与携程行程场景天然契合（机酒门票消费自动入账）。

### 1.3 与赛事目标的关键差距（结论先行）

**当前 demo 最大的风险：AI 含量不足。**
现状的"智能"只有 OCR 一项，且 OCR 的腾讯云调用是**空实现（stub）**，演示模式下返回假数据——
一旦评委追问"AI 在哪里"，作品会非常被动。因此本次优化的 **P0 主线是把 AI 能力做成真的、可当场演示的**。

## 四、技术设计要点

### 4.1 AI 引擎（规则保底 + LLM 可选）为什么这样设计

黑客松现场最常见的翻车点是"联网 AI 演示失败"。因此采用**双轨解析**：

```
用户输入 ──► 规则引擎（本地、毫秒级、离线可用）──► 结构化账单
                 │ 置信度低
                 └──► LLM 接口（可选，配置密钥后启用）──► 结构化账单
```

- 规则引擎覆盖旅行 AA 高频表达（"打车去机场86块，我垫的，和小红小李平分"），离线可演示；
- LLM 接口处理长尾表达，失败自动回退规则引擎——**演示永不失败**；
- 三端（小程序 / 浏览器 demo / Node server）复用同一份 `ai.js`，算法内核单一来源。

### 4.2 自然语言解析字段

| 字段 | 示例输入命中 | 实现 |
|---|---|---|
| amount | "86块"、"¥238"、"一共328元"、"3个人240" | 金额正则 + 上下文优先级（实付/合计优先） |
| currency | "86美元"、"12000日元" | 币种词典，默认 CNY |
| category | "打车"→交通、"居酒屋"→餐饮 | 关键词加权打分 + 模糊包含 |
| payer | "我垫的"、"小红付的"、"小王请客" | 代词映射 + 成员名匹配 |
| splitType | "AA/平分"→equal、"我请客"→treat、"小红出600"→custom | 表达词典 |
| splitWith | "和小红小李平分"→[小红,小李] | 成员名在句中出现检测 |
| description | 剔除金额/分摊语义后的名词短语 | 模板裁剪 + 模糊分类回填 |

### 4.3 均分尾差修复（最大余额法）

```
floor = Math.floor(amount*100) / n   // 先按分向下平摊
remainder = amount*100 - floor*n      // 余下的分按顺序逐人补 0.01
```
保证 `sum(splits) === amount` 恒成立，杜绝"账不平"。

## 六、赛前演示脚本（3 分钟版）

1. **开场（20s）**：一句话痛点——"旅行回来对账，翻聊天记录翻到吵架"；
2. **AI 记账（60s）**：demo 输入"昨天晚饭花了328，我先垫的，跟小红小李平分"→ 逐字段解析动画 → 一键入账；
3. **AI 票据识别（30s）**：showcase 页扫描支付宝截图 → 自动提取金额/商户/时间；
4. **一键结算（40s）**：8 笔账 → 每人净额 → 贪心 3 笔转账收尾，AI 生成结算摘要一键复制；
5. **AI 消费洞察（30s）**：消费报告、人均/日均、TOP 分类、省钱建议；
6. **收尾（20s）**：携程生态展望（行程订单自动入账）+ 演示模式卖点（无网可跑）。

**演示保险**：全程离线可跑（规则引擎保底）；`demo/showcase.html` 的"自动演示"按钮可一键走完全流程，防手忙脚乱。
