# ✈️ TravelAA · 旅行 AA 记账

> 一句话、一张截图、一条携程订单，就能把旅行账单记明白；旅行结束一键清账。
> 面向**多人出行的 AA 场景**：垫付分散、事后对不上账、外币算不清、算账伤感情。

---

## 🎯 先看这个：交付物是什么

| 交付物 | 位置 | 说明 |
|---|---|---|
| **网页 Demo（主交付物）** | `demo/index.html` | **离线可用、无需服务器与任何 API Key**；需要同目录一起拷贝（见下方说明） |
| 微信小程序端 | `apps/miniprogram/` | 原生小程序（5 个页面），演示数据模式可独立跑 |
| 微信云函数 | `apps/cloudfunctions/` | login / 房间 / 账单 / 成员 / ocr / settle 等 9 个 |
| 可选后端 API | `server/` | Express + SQLite，提供 AI 增强（不启动也不影响 Demo） |

> ⚠️ **「单文件双击即开」是错的，别这么说**。`demo/index.html` 通过 `<script src>` 引用了三份
> **UMD 共享内核**（`apps/miniprogram/utils/{ai,ctrip,sync}.js`）与 `demo/assets/vision-samples.js`，
> 还从 Google Fonts 取字体（取不到会自动回退系统字体，排版仍正常）。
> 所以正确说法是：**整个项目目录拷过去，双击 `demo/index.html` 即可离线运行**；
> 只发一个 html 文件会白屏。

**给评委/观众看的就是 `demo/index.html`**（网页版），打开后：

- **首屏就装得下**：品牌行 + 工具条 + 解说条 + 4 台完整手机 —— 1366×768 的笔记本也不用滚动
  （手机高度按视口自适应，4 台永远排成一行、不裁边）；
- 点 `▶ 自动演示` 看完整剧情（24 个分镜约 82 秒，可用 `⏩` 切 0.7× / 1× / 1.4×），
  或点 `🎬 导览` 按 **15 步**逐步听讲解（同类功能已合并，仍覆盖全部 40 项功能）；
- 工具栏下面是**常驻解说条**：`分镜 3 / 24` + 进度条 + 「这一步在做什么」，
  旁边有 `⏭ 下一步`（单步讲解）/ `⏸ 暂停`；
- **往下滚**还有"给评委看的一屏"：产品定位、五层 AI 能力、工程可信度（9 套 / 861 项断言，
  其中页内自检与交互验收是**点一下真实跑出来的**）、以及**诚实边界**（能说什么 / 不能说什么）。

**刷新不丢**（`localStorage`）与**多窗口实时同步**（`BroadcastChannel`）都是自动探测的：
探测得到就启用、探测不到就降级为单页联动，工具条上的同步徽标会**如实显示当前处在哪一档**。
实测 Edge/Chrome 下 `file://` 双击打开也能刷新不丢；想看真实跨窗口同步，就再开一个标签页打开同一路径
（用本地服务器打开如 `npx serve .` 最稳；**提交给评委时建议放静态站点**，这样多窗口同步与刷新留存都能生效）。

## 🚀 5 分钟跑起来

```bash
# ① 网页 Demo：双击 demo/index.html（Chrome / Edge）
#    打开即可看：4 台手机一屏装下 → 点「▶ 自动演示」或「🎬 导览」
#    想确认没问题就先点「🩺 自检」，出现 22/22 PASS 即可放心

# ② 跑全量验收（Node ≥ 20，无需安装任何依赖）
node tests/run-all.js        # 9 套测试一把梭；等价于 npm test
#    也可以单跑某一套：
node tests/ai.test.js        # 共享算法内核
node tests/v3.test.js        # V3 旅行记账语义（抹零/代购/多退少补/暂估改价）

# ③ 可选：自建后端 + AI 增强（不配 Key 也能启动，自动降级到本地规则引擎）
cd server && npm install && npm start     # http://localhost:3000/api/health
```

> 详细步骤与演示话术见 **`docs/上手与演示脚本.md`**。

## 🤖 五层 AI 能力（全部可在 Demo 中现场验证）

| 层 | 能力 | 现场怎么演 |
|---|---|---|
| **会听** | 一句话 / 语音记账 | 记一笔页输入「打车去机场86块，我垫的，和小红小李平分」→ AI 自动填好金额、分类、付款人、分摊 |
| **会看** | 票据 / 订单截图识别 | 记账方式页 → 票据识别（微信/支付宝/小票/发票）或订单截图识别 |
| **会读单** | 携程订单入账 | 记账方式页 → 携程订单 → 选内置样例 → 解析 → 一键入账 |
| **会算账** | 多币种 + 最简转账 | 结算页：贪心算法给出最少转账笔数，外币按记账时汇率快照折算人民币 |
| **会复盘** | 审计 / 统计 / 小作文 | 房间页 AI 审计、`STATS` 统计页（分类占比 + 每日趋势 + 洞察）、结算页生成小作文 |

**技术上的三层解析**：本地规则引擎（毫秒级、离线保底）→ 可选大模型（自备 Key，自动升级）→ 失败自动回退，**现场演示不会翻车**。

### 🧭 诚实边界（对外表述请严格遵守）

- ✅ 可以说：**订单文本/截图 → 账单的识别入账管线已打通**；语音与票据识别是成熟能力调用。
- ⚠️ 截图识别需要多模态模型：未连接 AI 通道时，Demo 明确标注为「内置样例识别结果」，**不冒充模型实时输出**。
- ⚠️ 携程**自动拉单**需要携程开放平台授权，当前为**对接点已预留**，演示的是同一条数据管线，**不要说"已接入携程系统"**。
- ⚠️ 视觉/语言模型均非自研，属于能力集成与工程化。

## 📁 目录结构

```
travel-aa/
├── README.md                 # 本文件：项目总览
├── demo/                     # ⭐ 网页 Demo（主交付物）
│   ├── index.html            #    多机联动 + 全部功能（单文件、离线可用）
│   └── assets/               #    订单截图样例（base64 内嵌）
├── apps/
│   ├── miniprogram/          # 微信小程序（pages + utils 共享内核）
│   └── cloudfunctions/       # 微信云函数（9 个）
├── server/                   # 可选后端 API（Express + SQLite）
├── tests/                    # 9 套自动化验收（run-all.js 统一编排）
├── docs/                     # 文档（含 archive/ 已废弃内容）
├── .github/workflows/ci.yml  # CI：Node 20/22 上跑 npm test
└── project.config.json       # 微信开发者工具配置（已指向 apps/）
```

**共享算法内核**：`apps/miniprogram/utils/` 下的 `ai.js`（AI 解析/审计/预算/洞察/结算口径）、
`ctrip.js`（携程订单解析）、`sync.js`（多窗口合并/墓碑/rev）为 UMD 模块，
**小程序、网页 Demo、Node 服务端三端复用同一份代码**——算法只维护一处，不会出现三份实现互相漂移。

### 🎬 演示入口一览

| 打开方式 | 效果 |
|---|---|
| `demo/index.html?n=4` | 4 台手机开场（4 位成员，每人都会动手） |
| `▶ 自动演示` / `?n=4#auto` | 24 个分镜的完整剧情（AI 记账 / 票据 / 携程订单 / 截图识别 / 抹零 / 代购 / 私账 / 多退少补 / 暂估改价 / 占位 / 审计 / 结算 / 结清闭环 / 复盘）→ **结束时弹收官总结**（真实算出的总消费/人均/最少转账/账恒平） |
| `🎬 导览` / `?n=4&tour=1` | **15 步**导览（同类功能合并，覆盖全部 40 项功能）；`tour=N` 可直达第 N 步 |
| `?n=4&stage=10#auto` | 自动演示定格在第 10 步（便于截图／讲解） |
| `#selftest` / `#tourtest` / `#uitest` | 22 / 17 / 91 项浏览器内验收 |

**演示模式下屏幕上会浮一条解说栏**，给评委补齐三件事：产品名与团队、分镜进度（`分镜 15 / 24` + 进度条）、
以及**当前这一步在演什么**（15px 解说正文）；**正在操作的那台手机会加一圈高亮环**，字幕条写着
「小明 · ⑩ 智能抹零」—— 谁在做、在做什么，一行读全。

**讲者可控**：`⏸ 暂停`（讲两句再继续）、`⏭ 下一步`（**单步讲解**，一个分镜停下等人点）、
导览卡上的 `⏩ 1×` 切三档语速。

**投影仪安全**：4 台手机固定宽 1334px，1280×720 的投影仪放不下 —— 会自动**等比缩小**到刚好装下
（实测 1280×720 下 `scale(0.899)`：4 台始终同一行、不裁边、无横向滚动）。

> 加功能时**必须**在 `demo/index.html` 的 `FEATURES` 清单里加一行，并给某个导览步骤补 `covers` ——
> 否则 `#selftest` 会红。原因很简单：**做了但演示里看不见的功能，等于没做。**

## ✅ 验收标准（交接前已全部通过）
